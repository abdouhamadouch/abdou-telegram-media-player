# Abdou Telegram Media Player

Arabic-enabled adaptation of [antlis/tg-streaming-bot](https://github.com/antlis/tg-streaming-bot), a Telegram voice-chat audio/video streaming bot built with Pyrogram and py-tgcalls.

## Status

The upstream source has not yet been copied into this repository. Do not deploy this repository until the source files and Arabic command aliases have been added and tested.

## Planned Arabic aliases

- `/شغل` — `/play`
- `/فيديو` — `/vplay`
- `/بث` — `/vstream`
- `/بحث` — `/search`
- `/ايقاف` — `/pause`
- `/استمرار` — `/resume`
- `/تخطي` — `/skip`
- `/انهاء` — `/stop`
- `/قائمة` — `/playlist`
- `/مساعدة` — `/help`
